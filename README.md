# הנגרייה שלי - WoodCraft

אפליקציית PWA בעברית (RTL) לתכנון ובניית פרויקטי נגרות ביתיים. הנתונים נשמרים במכשיר בלבד (IndexedDB), ללא הרשמה, וללא שירותים או מפתחות API בתשלום.

## הרצה למפתחים

```bash
npm install
npm run dev            # סביבת פיתוח
npm test               # כל הבדיקות (134)
npm run build          # בדיקת TypeScript ובניית ייצור ל-dist/ (עם PWA)
npm run preview        # הרצת dist/ מקומית, לבדיקת PWA
npm run build:single   # קובץ HTML יחיד ל-dist-single/index.html (ללא שרת)
npm run verify         # בדיקות + בנייה
```

## הפעלה בלי התקנה ובלי שרת

קובץ `dist-single/index.html` (כ-2.2 MB) הוא האפליקציה כולה בקובץ אחד. פותחים אותו בדפדפן (Chrome, Edge, Firefox או Safari) בדאבל-קליק. הנתונים נשמרים באותו דפדפן. בגרסה זו אין Service Worker, ולכן אין עבודה לא מקוונת מותקנת ואין התקנה כ-PWA. לשימוש מקוון ומותקן יש להשתמש בגרסת ה-PWA.

## פריסה חינמית (GitHub Pages)

קובץ `.github/workflows/pages.yml` מריץ בדיקות, בונה ומפרסם את `dist/` ב-GitHub Pages בכל push ל-`main`. הדרוש: מאגר ב-GitHub, ו-Pages מוגדר לפי "GitHub Actions" בהגדרות המאגר. אין צורך בכרטיס אשראי. הבנייה משתמשת ב-`HashRouter` ו-`base: './'`, לכן הניווט עובד בכל נתיב סטטי.

האימות של תהליך הפריסה לא בוצע בסביבת הפיתוח. הוא ייבדק בפעם הראשונה שהוא ירוץ ב-GitHub.

## מה עובד היום

- ממשק עברי מלא עם RTL, ניווט תחתון לחמישה אזורים: בית, קטלוג, תכנון, הפרויקטים שלי, ספקים.
- קטלוג של 36 דגמים ב-6 קטגוריות. כולם בסטטוס **לא מאומת** פרט לתוכניות הטיוטה המפורטות להלן.
- יצירת פרויקטים, עריכת שם/סטטוס/הערות ומחיקה, מועדפים.
- שלושה דגמי טיוטה עם מנוע מידות: קופסת אחסון (`storage-box`), מעמד לטלפון (`phone-stand`), ארגונית שולחן (`pen-holder`). התוכניות בתיקייה `src/domain/plans/`.
- מנוע מידות (`src/domain/engine.ts`) שמחשב מחדש בכל לחיצה על "התאם למידות שלי": חלקים, כתב כמויות ומחברים. הוא בודק טווחים, עובי מותר, התאמה למקום פנוי, תקינות גאומטרית (חלק בתוך המידות החיצוניות, ללא חפיפה נפחית בין חלקים) ומגבלות תכנון.
- שרטוטי SVG (חזית, צד, מבט על, מבט מפורק, ושרטוט הרכבה לכל שלב) נבנים מחדש מהמידות הנוכחיות.
- שמירה אוטומטית ב-IndexedDB של מידות, הערות, סימוני רכישה וסימוני שלבים שהושלמו. הנתונים נשמרים גם אחרי סגירת הדפדפן.
- ייצוא: Excel עם שלושה גיליונות בכיוון RTL, CSV עם BOM לעברית, ו-PDF אמיתי (A4, עמודים, שרטוטים, חלקים, חומרים, שלבים). תוויות הכותרת התחתונה ב-PDF באנגלית בלבד, כי הגופן המובנה בספריית ה-PDF אינו תומך בעברית.
- גופן Heebo מוטמע בחבילה, ללא פנייה לשירותים חיצוניים.

## הרצת הבדיקות

- `src/tests/` כולל 134 בדיקות: קטלוג, מנוע (חפיפה, גבולות, התאמת מידות), תוכניות (שלוש תצורות לכל דגם, עובי, חומר, התאמה למקום, חוזה לכל תוכנית), שרטוטים, ייצוא (CSV, Excel נקרא חזרה), ושמירה (IndexedDB עם fake-indexeddb).
- בדיקות קצה (Playwright עם Chrome מקומי, 31 בדיקות): שמירה אחרי הפעלה מחדש של הדפדפן, ייצוא Excel/CSV/PDF, תצוגה במובייל (390px) בלי גלילה אופקית, וכפתורי הניווט. הסקריפט נמצא מחוץ למאגר (`/home/claude/smoke/e2e.mjs`) ועדיין לא הועבר למאגר.

## כללי אמינות (מחייבים)

- אין להזין מידות, חומרים, מחברים או שלבי בנייה שלא נבדקו ממקור מאומת.
- כל תוכנית טיוטה מסומנת `review: 'draft'`, ו-`verification` נשאר לא מאומת. המערכת מציגה את התוצאה כ"טיוטה, לא מאומתת לבנייה".
- מפרטי מחברים (קוטר ואורך) מסומנים "נדרש מפרט מאומת" עד שייבדקו מקור.
- בדיקות תוכנה אינן תחליף לבדיקה מקצועית של נגר או מהנדס.
