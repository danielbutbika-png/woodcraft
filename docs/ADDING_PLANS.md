# תהליך הוספת תוכנית דגם

המטרה: לא להוסיף תוכן פיקטיבי. כל תוכנית עוברת את השלבים הבאים, לפי הסדר.
רשימת הבדיקה היא גם מה שהמערכת בודקת אוטומטית (`src/tests/plansContract.test.ts`).

## 1. מקורות

- אספו מקורות ציבוריים לתוכנית: פרסום של יוצר תוכנית עם מידות, ספר נגרות, או מפרט של יצרן חומר.
- רשמו כל מקור ב-`sources` של התוכנית (כותרת וקישור). בלי מקור אין תוכנית.
- אם המקור סותר את הנתונים שלכם, עצרו והכריעו לפני שממשיכים.

## 2. משתנים וטווחים

- הגדירו ב-`variables` רק מידות שהמשתמש צריך לשנות, עם טווח מינימום ומקסימום.
- טווחים נבחרים לפי המקור ולפי מה שחלק בפועל יכול להחזיק, לא לפי נוחות.
- עובי ה-`allowedThicknesses` חייב להיות מאושר ממקור לחומר המתאים.

## 3. גיאומטריה

- `buildParts` מחזיר כל חלק עם `placements`: תיבה אחת לכל יחידה.
- מידות התיבה חייבות להתאים ל-`length`, `width`, `thickness` של החלק. המנוע בודק זאת.
- המנוע דוחה חפיפה נפחית בין חלקים, וחלק שחורג מהמידות החיצוניות.
- כשיש תנאים נוספים (למשל מקום לטלפון, רוחב תא מינימלי), הוסיפו אותם ל-`checks`.

## 4. מחברים וחומרים

- כל מחבר נכנס ב-`hardware` עם כמות ושימוש. המפרט (קוטר ואורך) נשאר `SPEC_PENDING` עד שמפרט מאומת נמצא במקור.
- כל חומר ב-`woods` מקבל הערה כללית, ואסור להניח שכל סוגי העץ זהים.

## 5. שלבי הרכבה

- כל חלק חייב להופיע בשלב הרכבה אחד בדיוק (`partIds`). הבדיקה נכשלת אחרת.
- שלב של הכנה או גימור לא מקבל `partIds`.
- שרטוט ההרכבה נבנה מהמיקומים האלה, כך שהוא מתאים בדיוק למידות.

## 6. סטטוס בדיקה

- `review: 'draft'` ו-`verification: 'unverified'` הם ברירת המחדל לכל תוכנית.
- רק בדיקה מקצועית של נגר או מהנדס, מתועדת במסמך נפרד, מאפשרת לשנות ל-`reviewed` ול-`verified`.
- בדיקת תוכנה אינה מחליפה בדיקה מקצועית, והיא לא מעניקה סטטוס מאומת.
- כשתוכנית מסומנת `reviewed`, החוזה דורש שיהיו מקורות רשומים.

## 7. בדיקות

```bash
npm test
```

כל הבדיקות חייבות לעבור. החוזה לכל תוכנית בודק: שיוך לקטלוג, שלבים, כיסוי חלקים, מחברים, מקורות וסטטוס.
לפני פרסום, הריצו גם `npm run build` ו-`npm run preview`, ובדקו את הדגם בדפדפן במובייל.

## 8. הוספה לקטלוג

- הוסיפו את התוכנית ל-`src/domain/plans/index.ts` עם מזהה הדגם בקטלוג.
- הדגם בקטלוג נשאר בסטטוס לא מאומת עד שהתוכנית נבדקה.
